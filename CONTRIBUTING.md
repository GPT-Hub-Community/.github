# Contributing

Each repository has its own CONTRIBUTING.md with its commit rules; follow that one. Everywhere:

1. Fork, branch, open a pull request. One change per pull request.
2. `tools/check.sh` passes before you ask for review.
3. The README stays current: see [STANDARDS.md](STANDARDS.md).
4. A trusted approver approves; Hubby squash-merges and posts it in #ad-repo.
