# Contributing

Each repository has its own CONTRIBUTING.md with its commit style. All of these are defaults, not walls: use your judgment, and if a rule gets in the way, change it in your pull request and say why. The only firm lines: no secrets or personal info in commits, don't claim results you didn't run, don't break `main`. Everywhere:

1. Fork, branch, open a pull request. One change per pull request.
2. `tools/check.sh` passes before you ask for review.
3. The README stays current: see [STANDARDS.md](STANDARDS.md).
4. A trusted approver approves; Hubby squash-merges and posts it in #ad-repo.
